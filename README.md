# 🎬 Movie Ticket Booking System

> A menu-driven Movie Ticket Booking System developed in modular C++,
> demonstrating Object-Oriented Programming, SOLID principles, UML-based
> system design, and multiple payment methods.

---

## 📌 Project Overview

The **Movie Ticket Booking System** is a console-based application developed
as part of the **TCS-504 – System Design** assignment.

The system allows users to browse available movies and shows, select seats,
calculate ticket prices, make payments, and generate tickets.

The project focuses not only on functionality but also on **clean software
architecture, modular design, OOP principles, and SOLID design principles**.

---

## ✨ Key Features

- 🎥 Browse available movies
- 🕐 View available shows
- 💺 Select and book seats
- 🎟️ Generate movie tickets
- 💰 Automatic ticket price calculation
- 💳 Multiple payment methods
  - UPI
  - Card
  - Cash
- 👤 Customer management
- 🏢 Cinema and show management
- 🧩 Modular C++ architecture
- 🛡️ SOLID-principle-based design
- 📐 UML class and sequence diagrams
- 🖥️ Menu-driven console interface

---

🏗️ System Architecture

The application is divided into multiple classes and components,
with each component responsible for a specific part of the booking process.
